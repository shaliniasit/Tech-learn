YOUR LEARNING JOURNEY

Courses & Learning Paths

Explore beginner-friendly topics with examples.

01. Computer Fundamentals

Learn about computers, hardware, software, files and folders.

Example: Identify the CPU, RAM, keyboard and monitor.

02. HTML Essentials

Learn to create the structure of a website using HTML.

Example: Create a heading, paragraph and link.

03. CSS Web Design

Learn colours, spacing, borders, typography and layouts.

Example: Design a technology card with a blue heading.

04. Responsive Design

Make websites display properly on phones, tablets and computers.

Example: Show three cards per row on desktop and one on mobile.

05. Python Introduction

Explore programming concepts such as variables and conditions.

Example: A program that adds two numbers.

06. Cyber Safety

Understand online privacy, password safety and secure browsing.

Example: Recognise a suspicious link.

07. Database Basics

Understand how information is organised and stored.

Example: A table of students and roll numbers.

08. Website Publishing

Learn how website files can be published online.

Example: Publish a static HTML/CSS website.

09. Introduction to AI

Learn the basic ideas behind artificial intelligence.

Example: Image recognition categorising photos.
